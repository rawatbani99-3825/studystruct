# C++ Study Planner — Analysis Module

## 1. Project Overview
The Study Planner is a C++ project designed to help students manage academic tasks, track completion status, and organize tasks based on priority and deadlines.

## 2. My Contribution
I worked on the **Analysis Module**, which provides an overview of tasks and helps users analyze their study progress.

## 3. Modules Implemented

### A. Overall Task Analysis
- Implemented `showOverall()` to display an overall analysis of tasks.
- Organized task information to provide a clear summary of study progress.

### B. Subject-Wise Analysis
- Implemented `showSubjectWise()` to analyze tasks according to individual subjects.
- Helped users understand their task distribution and progress across subjects.

### D. Graph-Based Analysis
- Worked with graph concepts to represent task relationships.
- Used BFS (Breadth-First Search) for overall graph evaluation.
- Used DFS (Depth-First Search) for subject-wise graph evaluation.

## 4. Data Structures and Algorithms Used
- **Arrays:** Task storage and management.
- **Stack:** Management of completed tasks.
- **Circular Queue:** Revision task organization.
- **Graphs:** Representation and analysis of task relationships.
- **BFS:** Overall graph traversal.
- **DFS:** Subject-wise graph traversal.
- **Merge Sort:** Sorting tasks according to deadlines.
